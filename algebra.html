Quadratic Equation Solver Guide

Using ax² + bx + c = 0, Discriminant (Δ) & Step-by-Step Roots

More Information

The Algebra quadratic tool solves second-degree equations written in standard form ax² + bx + c = 0, where a, b, and c are numerical coefficients and a is not zero. When you enter a, b, and c into the tool, it reads each coefficient and prepares to evaluate the equation systematically rather than guessing values by trial and error.

Standard Form: ax² + bx + c = 0  |  Δ = b² - 4ac  |  x = (-b ± √Δ) ÷ (2a)

In the second step, the tool computes the discriminant (Δ = b² - 4ac). This single number controls the solution path: when Δ > 0, you get two distinct real roots; when Δ = 0, both roots collapse into one repeated real value (-b ÷ 2a); and when Δ < 0, there are no real roots because taking the square root of a negative number leaves the real number system.

For example, when the tool solves x² + 5x + 6 = 0, it identifies a = 1, b = 5, and c = 6. It calculates Δ = 5² - 4(1)(6) = 25 - 24 = 1, then substitutes into the quadratic formula: x = (-5 ± √1) ÷ (2 × 1), producing x₁ = -2 and x₂ = -3.

When using or checking quadratic calculations by hand, watch out for sign errors on b when writing -b, forgetting to multiply by 2a across the entire denominator, or misapplying signs when c or b is negative. Always verify your roots by plugging them back into ax² + bx + c = 0.
